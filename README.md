## 🚀 Featured projects

### 🥾 [Lykkelig tur](https://github.com/guttormsen/lykkelig-tur) · [**Live demo →**](https://guttormsen.github.io/lykkelig-tur/)
A hiking planner for Norway that runs entirely in the browser. Finds marked trails near you,
builds elevation profiles from national laser-scan data (DTM1), shows hour-by-hour weather at
each checkpoint along the route, finds public transport to the trailhead, downloads maps for
offline use and keeps a trip journal. **No account, no tracking, no server.**
<br/>`JavaScript` `PWA` `Service Worker` `Leaflet` `Open data` `GitHub Actions` `Playwright` · 190+ unit tests, CI-deployed to GitHub Pages

### 🧠 [Jarvis](https://github.com/guttormsen/Jarvis)
A voice-controlled AI assistant running on a **local LLM** (Qwen 3 via Ollama). Listens for a
wake word, transcribes speech, lets a LangChain agent call tools and answers out loud with TTS.
<br/>`Python` `Ollama` `Qwen` `LangChain` `SpeechRecognition` `pyttsx3`

### 🤖 [agenten](https://github.com/guttormsen/agenten)
A Slack bot powered by Claude. Replies in DMs and threads, uses the thread history as context,
and can search the web, fetch pages and run code in a sandbox.
<br/>`TypeScript` `Node.js` `Slack Bolt` `Socket Mode` `Claude API`

### 📱 [Octopush SMS Sender](https://github.com/guttormsen/octopush)
A desktop GUI for sending bulk SMS through the Octopush API, with a custom sender ID.
<br/>`Python` `Tkinter` `REST API`

## 💡 How I like to build

- **Ship it tested** – unit tests for the logic, real-browser smoke tests, CI on every push.
- **Offline-first & private by default** – keep user data on the user's device when possible.
- **Open data, properly credited** – respect the APIs and their licences.
- **Mobile-first and accessible** – keyboard support, sensible touch targets, dark mode, reduced motion.
